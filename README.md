# Por Onde Andei

Este projeto é um local onde compartilho relatos de viagens, passeios e experiências em lugares que visitei.

Não é um somente um local de viagens e sim locais onde visito, como restaurantes, bares, parques, cachoeiras, praias e vários outros lugares que acho interessantes para compartilhar.

Não é nada profissional, somente um simples local para compartilhar minhas experiências e memórias de lugares que visitei, com fotos, relatos e dicas para quem quiser conhecer esses lugares também.
